# NutriFit - Projeto Integrador

Projeto de e-commerce voltado para suplementação e bem-estar, desenvolvido como uma landing page institucional com foco em conversão, identidade visual e experiência do usuário.

## 📌 Objetivo

Criar uma loja fictícia de suplementos com layout responsivo, foco em produtos para ganho de massa e emagrecimento, além de páginas de cadastro, login, contato e carrinho.

## 🧩 Stack

- HTML5
- CSS3
- JavaScript
- SQL

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Jlucaas95/Projeto_Integrador.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto_Integrador
```

3. Abra o arquivo `index.html` no navegador ou inicie um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```bash
http://localhost:8000
```

## 🏗️ Estrutura principal

- `index.html` — página inicial
- `cadastro.html` — cadastro de usuários
- `login.html` — autenticação
- `carrinho.html` — carrinho
- `contato.html` — página de contato
- `ganhoMuscular.html` — landing page de ganho de massa
- `emagrecimento.html` — landing page de emagrecimento
- `assets/css/` — estilos do projeto
- `assets/js/` — scripts JavaScript
- `img/` — imagens e ícones
- `BD-Nutrift/` — scripts e dados do banco
